# The development tools, pinned. install.sh installs them into a prefix: the
# dev container (/usr/local) and the VS Code Flatpak (/app) get the same set.
# Renovate bumps the versions (renovate.json, the "devtools" manager reads the
# comment above each line).
#
#   name  version  asset  checksum  members  license  [source]
#
# version   the upstream tag as published; {v} below is it verbatim, {n} is it
#           without a leading "v"
# asset     URL of the release file; go:<package> for `go install
#           <package>@{v}` (checked against sum.golang.org by go itself);
#           rustup for the Rust toolchain {v} (checked by rustup against the
#           channel manifest)
# checksum  URL of the file holding upstream's sha256 for the asset, or a
#           suffix to the asset URL (.sha256); sha256:<hex> where upstream
#           publishes none (Renovate's github-release-attachments datasource
#           rewrites it with the version); - where the asset is not a URL.
#           A URL may end in ,minisign:<public key> where upstream signs the
#           file with minisign: install.sh checks <URL>.minisig against the
#           key, so a new upstream key fails the build until the line has it
# members   comma list of src[:dst]: src is the path in the archive, or the
#           file itself; dst defaults to the basename of src and lands in
#           PREFIX/bin; a dst with a "/" is relative to PREFIX (a directory,
#           merged into what is there, when both end in "/"). For rustup: the
#           toolchain components.
# license   comma list of the license texts, which install.sh copies into
#           PREFIX/share/licenses/<name>/: paths in the archive (for go:, in
#           the module's source; for rustup, in the toolchain; ending in "/",
#           a directory's files), or URLs of upstream's files at the same tag
#           where the release has none, each ending in #sha256:<hex> of the
#           file (Renovate does not bump it: a version whose text changed
#           fails until the line has the new one); - in extensions.txt, where
#           each .vsix carries its own
# source    for a copyleft license (GPL, MPL) of the tool or of code built
#           into it (`go version -m` lists a Go binary's modules, Cargo.lock
#           at the tag a Rust one's crates), which asks for the way to the
#           source next to the binary: URL of the source at the tag (for
#           code built in, its go.sum or Cargo.lock names the version), which
#           install.sh writes into PREFIX/share/licenses/<name>/SOURCES
# A line may name Renovate's versioning after depName (versioning=...).
