# --- Wayland sessions ---------------------------------------------------------
# Five sessions, all listed by the greeter and all running the Noctalia shell:
# niri (scrollable tiling, preselected), labwc (stacking, the RDP default),
# sway (i3-style tiling), river (dynamic tiling) and wayfire (stacking with
# effects). Each was verified to run the shell, nested and software-rendered.
#
# What each needs beyond the package:
# - niri reads /etc/niri/config.kdl when the user has none; finalize.sh
#   generates it from the packaged default, with Noctalia and ghostty in
#   place of waybar/fuzzel/swaylock/alacritty.
# - labwc ships no wayland-sessions file (overlay provides it) and autostarts
#   from /etc/xdg/labwc/autostart.
# - sway rides its packaged config, which includes /etc/sway/config.d/*.
# - river is the river-classic package: Fedora's `river` 0.4 is only a
#   compositor core that needs a window-manager client Fedora does not
#   package. It has no system-wide init, so overlay/usr/bin/river-session
#   passes the image's one with -c.
# - wayfire reads only ~/.config/wayfire.ini, so overlay/usr/bin/
#   wayfire-session passes a config generated from the packaged example
#   (finalize.sh).
niri
labwc
sway
river-classic
wayfire

# --- Cockpit (web admin) -----------------------------------------------------
# Installed but off: `sudo systemctl enable --now cockpit.socket`, then
# http://localhost:9090. It only listens on loopback
# (overlay/usr/lib/systemd/system/cockpit.socket.d/). Pages: system, services
# (fail2ban included), logs, accounts, terminal, networking and firewall
# (-networkmanager), storage (-storaged), SELinux, files, diagnostics
# (-sosreport), podman containers (-podman, system and per-user). Fedora has no
# Cockpit plugin for docker or fail2ban. Left out on purpose: -packagekit and
# -ostree, whose update pages do not apply to a bootc system. The Metrics page
# is switched off by overlay/etc/cockpit/metrics.override.json (a condition
# that never holds); delete that file to get it back.
cockpit-ws
cockpit-bridge
cockpit-system
cockpit-networkmanager
cockpit-storaged
cockpit-podman
cockpit-selinux
cockpit-files
cockpit-sosreport
